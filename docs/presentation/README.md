## ⚡ 10-Second Quick Start

1. **Start the app:**
   ```bash
   bun run dev
   ```
2. **Open in Chrome:** Go to `http://localhost:3000` and press `F11` (Full-screen).
3. **Switch screens using keyboard shortcuts:**
   - `Alt + 1` ➔ **Site Map** (The South Pole map)
   - `Alt + 2` ➔ **Analyze** (The mountain skyline & rocket delay slider)
   - `Alt + 3` ➔ **Compare** (The landing spot tournament)
   - `Alt + 4` ➔ **3D Lab** (Drive the rover and astronaut helmet HUD)
